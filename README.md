# AprijalSHOP

Frontend website marketplace jual-beli akun game.

## Menjalankan
1. Extract folder.
2. Buka `index.html` di browser.
3. Semua fitur pada versi ini adalah demo frontend dan berjalan tanpa server/database.

## Struktur
- `index.html` — halaman utama dan modal
- `style.css` — desain responsive
- `script.js` — katalog, filter, keranjang, modal, toast

## Tahap berikutnya untuk menjadi marketplace sungguhan
- Backend + database user/listing/transaksi
- Login/register aman
- Dashboard admin & seller
- Upload gambar listing
- Payment gateway
- Sistem escrow/order
- Chat pembeli-penjual
- Verifikasi seller
- Notifikasi email/WhatsApp
- Terms & policy yang sesuai aturan game dan hukum yang berlaku

Catatan: jual-beli akun dapat dilarang atau dibatasi oleh ketentuan layanan game tertentu. Pastikan marketplace mematuhi aturan game, penyedia pembayaran, dan hukum yang berlaku.
